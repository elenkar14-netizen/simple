## Ограничения

Выборка — самые вовлечённые пользователи за сорок минут одного дня. Молчаливое большинство
и отток в неё не попали. Упоминаний рассылок, пушей, цены и подписки в данных нет, поэтому
выводов по коммуникационному каналу здесь тоже нет. Всё в разделе 09 — гипотезы, а не факты.
